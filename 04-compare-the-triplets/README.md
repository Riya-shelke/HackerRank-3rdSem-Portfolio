## Problem: Compare the Triplets
**Link:** https://www.hackerrank.com/challenges/compare-the-triplets/problem
**Topic:** Basic Implementation

### Approach
Compare a[i] with b[i] for the three categories. The larger rating gives its owner one point; ties give nobody a point. Return Alice's and Bob's scores as a two-element array.

### Complexity
- Time: O(1)
- Space: O(1)

### Notes
Only strict comparisons score points, so equal ratings must not add to either total.
